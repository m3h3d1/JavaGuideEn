This page brings together JavaGuide's learning roadmaps to help you choose a path for your goals instead of jumping between articles. These are the latest editions for 2026.

If you're preparing for a backend interview, start with the Java backend roadmap. If you already have a Java or Go backend foundation and want to move into AI application development or agents, start with the AI application development roadmap. If you want to deliver complete features independently, see the full-stack roadmap. If you're preparing for test development, test automation, or AI testing, see the test development roadmap.
