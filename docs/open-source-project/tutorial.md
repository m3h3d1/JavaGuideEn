This page lists resources suited to structured study or topic-based reference. Complete business systems are listed under [Practical Projects](./practical-project.md), and frameworks and middleware under [Frameworks and Infrastructure](./system-design.md).

## Java Fundamentals and Advanced Topics

- [JavaGuide](https://github.com/Snailclimb/JavaGuide "JavaGuide"): A learning guide covering core Java, databases, system design, distributed systems, high performance, and interview preparation.
- [toBeBetterJavaer](https://github.com/itwanger/toBeBetterJavaer): An accessible and engaging Java guide covering Java fundamentals, the Collections Framework, concurrency, the JVM, and enterprise Java development (Git, SSM, Spring Boot).
- [advanced-java](https://github.com/doocs/advanced-java "advanced-java"): Advanced topics for Java engineers, including high concurrency, distributed systems, high availability, microservices, and large-scale data processing.
- [bestJavaer](https://github.com/crisxuan/bestJavaer): A series of tutorials on Java fundamentals, the JVM, concurrency, databases, and middleware.
- [java-design-patterns](https://github.com/iluwatar/java-design-patterns "java-design-patterns"): Design patterns implemented in Java.

## Spring Code Examples

- [Building an Application with Spring Boot](https://github.com/spring-guides/gs-spring-boot): An official Spring getting-started guide that builds a working Spring Boot application with minimal configuration.
- [Building REST services with Spring](https://github.com/spring-guides/tut-rest): An official Spring REST tutorial covering resource modeling, HTTP APIs, and hypermedia.
- [Baeldung Tutorials](https://github.com/eugenp/tutorials): Java and Spring examples accompanying Baeldung articles. The repository is large, so browse by module rather than reading it from start to finish.

## Computer Science Fundamentals

- [cs-self-learning](https://github.com/PKUFlyingPig/cs-self-learning): A self-study guide that collects high-quality computer science courses from universities in Europe and the United States.

## Algorithms and Data Structures

- [The Algorithms - Java](https://github.com/TheAlgorithms/Java): Common algorithms and data structures implemented in Java. Use the code to understand the ideas or as a reference for practice problems. Check each implementation's complexity notes and test coverage; do not copy example code directly into production.

## Open-Source Books

- [_The Philosophy of High Concurrency_](https://github.com/johnlui/PPHC): Discusses a principle behind high-concurrency problems: identify bottlenecks and split them up.
- [Chinese translation of _Designing Data-Intensive Applications_ (DDIA)](https://github.com/Vonng/ddia): A Chinese translation of _Designing Data-Intensive Applications_.
- [_Phoenix Architecture_](https://github.com/fenixsoft/awesome-fenix): Discusses how to build reliable, large-scale distributed systems.
