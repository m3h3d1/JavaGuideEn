This **Knowledge Planet guide collection** brings together structured learning resources for Java interviews, system design and scenario questions, handwritten RPC, source-code reading, and practical projects.

If you are preparing for a Java backend interview, start with [The Java Interview Guide](./java-mian-shi-zhi-bei.md) and [High-Frequency Backend System Design and Scenario Questions](./back-end-interview-high-frequency-system-design-and-scenario-questions.md). To build project and source-reading experience, continue with the [AI mock-interview platform and RAG knowledge base](./interview-guide.md), [Build an RPC Framework](./handwritten-rpc-framework.md), and [Java Source-Code Reading Guides](./source-code-reading.md).

## Who Should Read This?

- Candidates preparing for Java backend interviews at new-graduate or experienced-hire levels, including larger companies.
- Readers who want structured materials instead of fragmented searches.
- Backend developers building skills in system design, scenario questions, projects, and source-code reading.
- Readers who want a more complete learning path and resources alongside JavaGuide's open-source content.

## Key Topics

- Interview preparation should cover fundamentals, project experience, system design, scenario questions, and communication.
- System design and scenario questions focus on breaking down problems, capacity estimates, critical flows, data consistency, and availability.
- Building an RPC framework connects networking, serialization, service registries, dynamic proxies, and service governance.
- Read source code with specific questions in mind. Focus on framework design and engineering practices you can apply elsewhere.
- A practical project is useful for interviews when you can run it, explain it, and make changes to it.

## Suggested Reading Order

1. [The Java Interview Guide](./java-mian-shi-zhi-bei.md): Establish a study plan for Java backend interviews.
2. [High-Frequency Backend System Design and Scenario Questions](./back-end-interview-high-frequency-system-design-and-scenario-questions.md): Study common scenarios such as URL shorteners, flash sales, deduplication at scale, and third-party login.
3. [AI Mock-Interview Platform and RAG Knowledge Base](./interview-guide.md): Build project experience and resume material through a complete application.
4. [Build an RPC Framework](./handwritten-rpc-framework.md): Understand distributed service calls by implementing a simple RPC framework.
5. [Java Source-Code Reading Guides](./source-code-reading.md): After building the fundamentals, study frameworks such as Dubbo, Netty, and Spring Boot.
